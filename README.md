# ВАШ ЛУЧШИЙ ОТДЫХ - анкета туриста
## 1. Что это
Учебный Python-проект для сбора заявок от туристов турагентства "Ваш лучший отдых". Программа последовательно задает вопросы о поездке, собирает информацию о туристах и выводит готовую сводку заявки.
## 2. Как проверить, что работает
1. Запустить программу и ответить на вопросы.
2. После заполнения анкеты программа выводит сводку заявки туриста со всеми введенными данными.
## 3. Что я сделала на этом уроке
- создала Python-проект и настроила виртуальное окружение
- разработала анкету туриста с помощью функции input()
- реализовала вывод собранных данных с помощью print() и f-строк
- создала репозиторий GitHub и научилась сохранять изменения с помощью Git-коммитов
